Paper Examiner

নিজের AI provider ব্যবহার করে সম্পূর্ণ প্রশ্নপত্র ও নিজের সমাধান মূল্যায়নের জন্য একটি private, local-first workspace।

কীভাবে কাজ করে

১. প্রশ্নপত্র দিন। সম্পূর্ণ প্রশ্নপত্র Question Paper-এ দিন। ছবি, লেখা বা দুটোই ব্যবহার করা যাবে।

২. সমাধান দিন। সম্পূর্ণ নিজের লেখা Your Solution-এ দিন। প্রশ্ন ধরে আলাদা করে সাজানোর দরকার নেই।

৩. Reconstruction। AI প্রশ্ন নম্বর, অংশ, নম্বর এবং উত্তরগুলোর সম্পর্ক পুনর্গঠন করে।

৪. Independent review। একাধিক আলাদা reviewer আলাদাভাবে উত্তর মূল্যায়ন করে।

৫. Adjudication। Main Agent reviewer-দের reasoning ও evidence বিচার করে। শুধু score average করে না।

৬. Report। নম্বর, percentage, প্রশ্নভিত্তিক ফল, strong/weak points, disagreement এবং actionable advice পাওয়া যায়।

Privacy

Paper Examiner client-side/local-first নকশার। আপনার paper browser-এ local storage-এ থাকে। পরীক্ষা চালালে প্রয়োজনীয় material আপনার নির্বাচিত AI provider-এর কাছে যায়। Evaluation pipeline-এর জন্য Paper Examiner-এর নিজস্ব application backend প্রয়োজন হয় না।

BYOK

নিজের API key ব্যবহার করুন। Provider ও exact model ID নির্বাচন করে configuration browser-এ locally save করা যায়। Site data clear করলে saved configuration-ও মুছে যাবে।

Input

Question Paper ও Your Solution—দুটিতেই text, একাধিক image বা mixed content ব্যবহার করা যায়। Evaluation-এর আগে item reorder করা যায়।

গুরুত্বপূর্ণ

AI marking একটি automated assessment; এটি official examiner-এর result নয়। বিশেষ করে handwriting, image quality, ambiguous question বা marking scheme অস্পষ্ট হলে evidence ও question-level reasoning যাচাই করুন।
